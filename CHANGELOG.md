# Changelog

## 4.5.0 — Windows beta

- Add an experimental per-user Windows installer.
- Use platform-specific data paths and an emoji renderer for Windows.
- Built-in emoji use packaged images; additional emoji use the Windows system font.
- After Effects on Windows has not yet been verified.

## 4.4.5

- Focus the documentation and panel guide on AE Emoji’s built-in workflow.

## 4.4.4

- Rename Sevemoji to AE Emoji while retaining compatibility with existing projects and settings.

## 4.4.3

- Show the reason auto-conversion is waiting, including file access, saving, and text editing mode.
- Recover a stopped or lost idle watcher while the panel is open.
- Add Restart auto-convert and clearer setup instructions.
- Retain the native emoji size and baseline fix from 4.4.2.

## 4.4.2

- Restore native glyph size and baseline measurements for normal and multiline text.

## 4.4

- Require `/s` or `/smoji` before codes in text; leave bare numeric/name codes as text.
- Support repeated inline commands and multiple separate emoji layers.
- Add editable personal numeric codes.
