How to Use AE Emoji

Use colorful Apple emojis while keeping your After Effects text editable. Every emoji stays on a separate layer and follows its text.

01

Write directly in After Effects

  1. Save your project with ⌘S.
  2. Create or select a normal text layer. Type Hello /s :smile, Hello /s :1, or paste Hello 😄.
  3. Finish editing with ⌘Enter, then press V to return to the Selection tool.
  4. AE Emoji converts the emoji automatically. Built-in emojis can continue to convert after the panel is closed.

Conversion pauses while a text layer is selected with the Type tool. Finish editing and press V to let it convert safely. New text layers are checked first; the 120 ms idle check interval is not the total conversion time.

02

Use codes or names

/s :1😄 smile/s :smile😄 smile/smoji :fire🔥 fire/s :heart:❤️ heart

Start each code with /s or /smoji, followed by a space. Plain :1 and :smile remain text. Names ignore capitalization; hyphens and underscores both work. Unknown codes stay unchanged.

Every command adds its own emoji, including repeated emojis at the start, middle or end: /s :smile this is a test /s :smile becomes 😄 this is a test 😄. Appending a command adds another emoji. To change an existing emoji, use Replace emoji.

03

Add from this panel

  1. Enter text with emoji commands or paste real emojis. Their positions are preserved.
  2. Optionally pick an extra emoji from the gallery or enter :1 in the dedicated Emoji field. This field accepts bare codes and adds the choice at the end.
  3. Click Add text + emoji. Each emoji gets its own layer.
  4. Change font, size, alignment and color in After Effects' Character and Paragraph panels.
04

Change an existing emoji

Select the emoji layer (or its text layer) in the timeline and click Load selected. Pick another emoji and click Replace emoji. Your text and its formatting stay in place.

When a text layer contains several emojis, select the specific emoji layer to replace it. Selecting the text layer loads its last emoji.

05

Favorites & Recent

Click the star on any emoji card to save it in Favorites. Click again to remove it. Recent contains your last 24 picks and conversions, including emojis entered directly in After Effects. Both lists stay on this Mac between sessions.

Search works inside the current collection. Hover a card to see its full name and code.

06

Trim, split & move

Select the text and its visible emoji layers together before trimming, moving them in time or using ⌘ShiftD to split. AE Emoji reconnects each split pair to its own measurement layer after you finish the edit.

You can change either segment's text independently. Replacing an emoji preserves the cuts you made. Keep the hidden measurement layers in the project; you do not need to select or edit them.

Emojis follow the native glyph size and baseline of the surrounding text, including wrapped lines. If an older emoji or split pair drifts, click Repair project. Keep auto-conversion enabled for automatic split repair.

07

TikTokText & multiple lines

Paste your text and emojis into TikTokText and create Boxed Text. AE Emoji converts its completed, unselected text layer automatically, even if the Type tool is still active. The colored emoji stays inside the original box. When editing the text directly in AE, finish with ⌘Enter, then V. Manual line breaks and paragraph text wrapping are supported.

08

Save & move your project

AE Emoji saves PNGs into a Sevemoji Assets folder next to your saved AEP. Keep that folder with the project when sharing or moving it.

A recovery copy is also stored in the project. Open AE Emoji and click Repair project to restore missing PNGs and fix split links, then save again.

09

If something does not convert

  • Read the status below Auto-convert. It identifies missing script file access, an unsaved project, text editing mode or a conversion error.
  • Open AE Emoji after each AE launch. Save the project, enable auto-conversion, then finish typing with Command+Enter and press V. Use the complete command /s :1; :1 alone stays text.
  • If auto-conversion has stopped, click Restart auto-convert. This does not change your AE or macOS security settings.
  • Use an unlocked 2D text layer, with the JavaScript expression engine enabled.
  • Source Text keyframes and expressions are left alone. There is no fixed emoji-count limit; longer text with many emoji layers takes more time to process. The panel accepts up to 6,000 characters.
  • Some joined family or profession emojis may be separated by After Effects when pasted. Those sequences may appear as separate emojis.
  • Text paths, right-to-left layouts and character animation are not fully supported.
10

Create your own codes and numbers

In Settings → Personal codes, enter a name and one emoji or a library code. Optionally assign a number from 61 to 999999, then click Save code. For example, name coffee, emoji ☕ and number 101 give you both /s :coffee and /s :101.

Click a saved entry to change its name, emoji or number, then click Update code. Clear Number to remove only its numeric code. New code clears the form; Remove deletes the entry. Numbers must be unique. Built-in names and numbers 1–60 stay reserved. Changes apply to future commands; existing emojis are preserved. Personal entries also appear in the emoji gallery.

11

Save an emoji appearance

Choose a preset, set size and vertical offset, give it a name and click Save preset. Saving with the same name updates that preset; a different name creates a new one. Use Default for new emojis to apply it automatically to future conversions.

Read selected copies the last selected emoji's values into the form. Apply to selected applies the values to selected emojis, or all emojis attached to selected text layers. You can undo this change in AE. Text fonts and sizes are edited in AE as usual. Presets and personal codes are stored on this Mac and survive restarts.
